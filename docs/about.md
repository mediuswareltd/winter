# About Winter

## Who maintains it

Winter is built and maintained by [Mediusware](https://mediusware.com), a software company that designs and ships products for clients worldwide. The source lives at [github.com/mediuswareltd/winter](https://github.com/mediuswareltd/winter).

## Why it exists

Multimodal retrieval over speech and keyframes so every answer is cited by timestamp.

We publish these tools so teams can evaluate the real software, not a slide deck: clone it, run it, and read how it is put together.

## Documentation

- Docs site: https://mediuswareltd.github.io/winter/
- Getting started, guide, and about pages are generated from the project README and kept next to the code under `docs/`.
