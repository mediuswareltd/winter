GitHub

Any video source

Drag-and-drop upload (mp4, mov, mkv, webm, mp3, wav…) or paste a YouTube URL

Timestamped transcripts

`faster-whisper` speech-to-text with voice-activity filtering; runs on CPU, faster on a GPU, 90+ languages

Visual understanding

Scene-change keyframe detection (OpenCV) plus CLIP image embeddings, so text queries find matching frames

Hybrid retrieval

Dense embeddings (BGE) and BM25 keyword search, merged with Reciprocal Rank Fusion

Multimodal answers

Transcript excerpts and the matching keyframes go to Claude, which answers with inline `[n]` citations

Clickable citations

Each citation is a timestamp chip; clicking it seeks the player. Source cards show the frame and excerpt
